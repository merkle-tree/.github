# Merkle

Software for managed IT service providers (MSPs).

### What we're building

- **Merkle platform**: RMM, PSA and AI in one place. An endpoint agent for macOS and Windows, a web console, and connectors to the vendor tools MSPs already run, such as Datto RMM and ConnectWise PSA.
- **Signals**: buying signals for MSPs. Dated events, such as a breach, an IT hire or an office move, that suggest a company may need an MSP now, turned into qualified leads with a way to reach them.

### Stack

Python (FastAPI, Postgres), Go, TypeScript (React), on AWS.
